PACKAGE SCOPE AND SOURCE SELECTION
==================================

We retained the supplied V6 parameter-tuning and Baseline numerical routines,
and the supplied V11 Basin experiment. We use the V11 figure style as the
publication plotting baseline.

We intentionally exclude:
- experiment_basin_v6.m and plot_basin_v6.m, because they implement the
  superseded two-corruption-level Basin path;
- plot_basin_final_eps.m and plot_basin_math_eps_v11.m, because the final
  Basin figure is generated by plot_basin_corruption_levels_v11_eps.m;
- V6 plotting and export scripts that generate PDF files;
- measurement-ratio and q-contraction experiments, which are outside the
  requested package scope;
- Gurobi-specific proximal routines, because the included experiments use
  the closed-form update and do not call Gurobi.

We have not changed the numerical formulas, random-seed schedules, trial
counts, or parameter grids in the retained experiment routines. We have
changed the output organization and the figure export/typography settings as
described in README.txt.

One source-level correction was necessary in tune_params_v6.m. The supplied
configuration stores corruption levels in cfg.corrupt_prob=[0.05 0.10], but
the pilot description specifies a single 10% corruption level. We therefore
use cfg.corrupt_prob(end) for pilot data generation and for the pilot-setting
label. The baseline and Basin routines continue to use the full corruption
level list where required.
